ReMemoris

Mystery Game | Godot Engine

ReMemoris is my first game project, focusing primarily on mystery and story exploration. The story itself is relatively simple and not very extensive, as the main focus of development was on understanding game systems and programming logic.

The game was developed using Godot Engine over approximately 20 days. During development, changes to the game's theme and story affected the overall development process and required adjustments to the game's progression.

Key Features

- Item Interaction:** A system that allows players to examine and interact with specific items through dialogue boxes and an in-game book interface.
- NPC Interaction:** A system that allows players to interact with NPCs to support exploration and story progression.
- Dialogue System:** A dialogue box system that displays conversations and information obtained by the player. Dialogue content varies depending on the character or object being interacted with and the current interaction state.
- Multiple Endings:** A branching ending system in which the outcome depends on the actions performed by the player throughout the game.

Technology and Assets

- Game Engine:** Godot Engine
- Programming Language: GDScript
- Game Assets:** Building and interior assets were created by me. Character sprites and animations were sourced from [The Adventurer Female by sscary](https://sscary.itch.io/the-adventurer-female), with minor modifications made to the character's hair and clothing.

Development Goals

The main goal of this project was to understand and implement the fundamentals of game development, starting with basic character movement and tile-based environments, then progressing to item interaction systems and other gameplay mechanics.

This project served as an opportunity to strengthen my understanding of programming logic and learn how different game systems work together within a single project.
